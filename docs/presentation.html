Огляд

Що таке Sekta і які проблеми вона має вирішувати

Набір незалежних сервісів обліку для військового підрозділу на спільному стеку, який працює офлайн у межах локальної мережі. Кожен самодостатній; усі закриті єдиним гейтом і мають наскрізний аудит «хто / коли / звідки».

Незалежність від кадрового потенціалу

Напрацьовані механізми збору й обробки інформації — робота не залежить від наявності фахівців зі знанням Excel чи інших інструментів.

Плановий облік + аналітика

Внесення поточної інформації та формування заявок у плановому режимі; у перспективі — аналітика по кожному напряму роботи.

Звіти та доповіді

Формування звітів і доповідей з наявної інформації за різні періоди.

Контроль помилок

Базовий набір обробки помилок у кожному сервісі — оперативно видно хибу чи недоопрацьований процес.

Синхронізація між секціями

Кожна секція веде свій напрям; напрацьована інформація одразу передається в сервіс іншої секції в частині, що її стосується.

HR

База даних S1

Повний облік військовослужбовця: від картки до кадрового руху, соцсупроводу й вітрини командира.

База данихповна картка в/сл: контракт, освіта, нагороди, поранення, родина; статуси ВПО/ТОТ Кадрирозрахунок наступного звання за днями на СБЗ, журнал змін «було → стало», кандидати-рекрути з етапами відбору РОСнагороди (№ наказу, статус, фото), автотранспорт з техпаспортом, близькі родичі, дні народжень Соцсупровіддіти о/с, облік поранень і лікування, відпочинок / відпустки S3позивні, проживання й контакти о/с для довідників і DOCX БПосвіта та спеціальності о/с; редагування блоку освіти прямо з таблиці Контрольперевірка повноти даних + строки до чергових звань; історія змін TVвітрина командира: стан кандидатів, звання, рух о/с
  • Наступні звання — розрахунок з урахуванням днів на СБЗ зі Стройовки (S1).
  • Заявки DOCX — на звання й на довідки, за формою.
  • Розшукова картка + донесення — PDF-картка в/сл, зведене донесення по о/с.
  • Вивантаження — Експорт БП (CSV), уся база в Excel, статистика за період.
  • ВПО / ТОТ — фільтри та позначки родини на окупованій території.
  • Контроль повноти даних — критичні поля одним поглядом + журнал історії.
S1

Стройовка

Наявність особового складу підрозділу в реальному часі: статуси кожного, зведення по офіцерах / сержантах / солдатах і готові відомості.

Стройовкаєдине місце вводу: статуси кожного, мультистатус (масова зміна багатьох ПІБ), поточні / майбутні статуси; підсумок офіцери / сержанти / солдати; друк · PDF по підрозділах Добова відомістьзріз наявності по підрозділах на обрану дату: за списком · у наявності · тимчасово відсутні за причинами; DOCX A4 Укомплектованістьза штатом vs наявно, некомплект, % укомплектованості по категоріях (штат задається в Адмінці); DOCX Відомість відсутніхтаблиця підрозділи × причини (відрядження, відпустка, лікарняні…) по офіцерах / сержантах / солдатах / рекрутах; DOCX Нарядисітка слотів чергової служби: клік → призначити / редагувати ПІБ на статус; діапазон дат з / по Узагальнені даніперіоди СБЗ і дні по кожному; зведення по статусах (СБЗ · відпустки · в строю · лікарняні); хто без відпустки за рік; Топ-10 за лікарняними; Рапорт 10к (DOCX)
  • Дні на СБЗ — джерело розрахунку вислуги в HR (S1).
  • Мультистатус + майбутні статуси — планувати відсутність наперед.
  • Друк / PDF / DOCX — готові відомості одним кліком.
  • Табло /stroyovka — публічна стройовка + добова.
S3

Графік службового навантаження

Матриця статусів особового складу по днях місяця, реєстр о/с, наряди й чергова служба — планування службового навантаження.

База о/среєстр: ПІБ · звання · посада · підрозділ · № групи; додавання, переміщення між підрозділами, фільтри активні / переміщені Внесення данихстатуси по днях (дата з / по); довідник статусів з пріоритетом (менше = вище) і прапорцем «у Наряди» Графікматриця-місяць: дні × о/с зі статусами, фільтр підрозділів, черговий загону, вакант; завантаження DOCX Нарядисітка слотів: клік → призначити / редагувати ПІБ на статус; діапазон дат Черговий /chкартка чергового загону + помічник, наряд дня, фото (лайтбокс)
  • Пікер місяць → графік — крос-віджет broadcast, свіжий SELECT.
  • Довідник статусів — пріоритет (менше = вище) + позначка «у наряди».
  • DOCX графіка — автоматичне формування Розділ 1 і Розділ 2, рендер таблиці 1:1 у документ.
  • Аудит + сповіщення — журнал змін розкладу.

Безпека · комплаєнс

Відповідність нормам безпеки

Система sekta-update реалізує базові профілі безпеки НАД № 409 (відкрита/конфіденційна) та № 419 (службова інформація; включає 409). Mapping — НД ТЗІ 3.6-006-24 / NIST 800-53. Технічну частину базових профілів фактично завершено.

Багатофакторність

IA-2 — TOTP + FIDO, стійкість до відтворення. Блокування спроб (AC-7).

Аудит append-only

AU-9 — журнал захищено від підробки: non-superuser роль, SECURITY DEFINER, REVOKE mutate.

Журнал змін «хто/коли/звідки»
